# CHANGELOG

## 2026-10-27 — MVP маршрутов курьеров

- Добавлены `Courier`, `Route`, `RoutePoint`; три тестовых курьера (`courier@`, `courier2@`, `courier3@demo.local`) с транспортом и вместимостью (ADR-0011).
- Реализован `RouteService`: черновик на курьера/дату, добавление/удаление/перестановка остановок, авто-порядок по прямой, подтверждение, проверки дублей и координат.
- Планирование блокируется после 10:00 для сегодня и для прошедших дат; подтверждённый маршрут не редактируется.
- Страница `/routes` (Staff): список маршрутов на дату, выбор даты/курьера, свободные заказы, остановки, карта 2ГИС с номерами и линией, демо-заказы в Development.
- Цех вынесен в конфиг `Depot` (`appsettings.json`): название, адрес, координаты; стартовая точка и линия маршрута на карте.
- API: `/api/couriers`, `/api/routes`, остановки/авто-порядок/подтверждение, `/dev/orders/demo`.
- 5 новых тестов: **28/28** зелёные; HTTP-смоук полного цикла маршрута.
- Исправлена Razor-разметка `disabled` у кнопки «Демо-заказы на дату» (выражение без скобок делало кнопку всегда неактивной).
- Маршруты теперь строятся по дорогам через **Directions API 2ГИС** (ADR-0012): геометрия, дистанция и время; цех — старт; fallback на прямую при ошибке/лимите 50 км.
- Авто-порядок остановок использует **Distance Matrix API + Or-opt** (ADR-0013): порядок по дорогам и односторонним улицам, fallback на прямую.
- Маршрут добавлен в change feed (`SyncEntityType.Route`); курьер видит подтверждённые маршруты на `/my-routes` с картой и остановками (ADR-0014). **32/32** теста.
- Исправлено: карта курьера не инициализировалась, если на выбранную дату маршрута не было (блок карты теперь рендерится всегда).

## 2026-10-27 — интеграция карт 2ГИС и точки доставки

- Выбран провайдер карт **2ГИС** (ADR-0009, закрыт вопрос `Q-2`).
- В `Point` и `PointSyncSnapshot` добавлены координаты `Latitude` / `Longitude`; `DevSeed` автоматически добавляет колонки в существующую SQLite-базу и проставляет демо-координаты точкам `7001` и `7002`.
- Реализован `PointService` и API `GET/POST /api/points`: создание/редактирование точек, запись в `SYNC_CHANGE` (`Point`), автоматическая разблокировка заказов при подтверждении точки на модерации (`PendingApproval` → `Active`).
- Добавлена страница `/points` («Точки на карте»): интерактивная карта, установка координат кликом, поиск адреса и модерация точек.
- Карта переведена на **MapGL JS API** с ключом из .NET user secrets (`TwoGis:ApiKey`); ключ не хранится в репозитории.
- Добавлен `TwoGisGeocoder` и API `GET /api/geocode`, `/api/geocode/reverse`, `/api/suggest`: подсказки адреса и автоопределение адреса по клику на карте.
- Переведены на русский системные комментарии в истории заказов, названия устройств и коды ошибок синхронизации в UI.
- 3 теста точек и 4 теста геокодера: **23/23 зелёные**.
