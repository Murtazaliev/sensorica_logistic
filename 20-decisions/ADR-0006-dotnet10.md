# ADR-0006. Целевая платформа — .NET 10

- Дата: 2026-10-27
- Статус: Accepted

## Контекст

Проект стартует с нуля. На машине установлен .NET SDK 10.0.402. Нужна актуальная LTS-версия с поддержкой EF Core, Blazor, MAUI и minimal API.

## Решение

- Все проекты target `net10.0`.
- EF Core 10.x.
- Blazor Server, MAUI и ASP.NET Core — на .NET 10.

## Последствия

- Плюс: свежие возможности языка/платформы, единая версия SDK.
- Минус: часть сторонних пакетов может отставать; проверить совместимость ЭДО/карт/MAUI-компонентов.
- ADR-0001 (общий стек) остаётся `Proposed` в части хостинга, карт и планировщика.
