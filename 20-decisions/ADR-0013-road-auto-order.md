# ADR-0013. Авто-порядок остановок по дорожной матрице

- Дата: 2026-10-27
- Статус: Accepted

## Контекст

После подключения дорожной геометрии (ADR-0012) порядок остановок всё ещё выбирался по расстоянию по прямой. Демо-ключ включает `distance-matrix-api`; нужно улучшить порядок с учётом дорог, не усложняя MVP асинхронным TSP/VRP.

## Решение

1. **Distance Matrix API.** `IRoadDistanceMatrix` / `TwoGisDistanceMatrix` вызывает `POST https://routing.api.2gis.com/get_dist_matrix?version=2.0` со всеми точками как `sources` и `targets`, `transport=driving`, `type=jam`. Сервер получает полную матрицу расстояний/времени (учитываются односторонние улицы).
2. **Локальный решатель.** Для одного курьера:
   - старт — цех (или первая остановка, если цех не настроен);
   - жадный «ближайший сосед» по дорожной матрице;
   - улучшение перемещением одной остановки (Or-opt) с полным пересчётом стоимости; стартовая точка не меняется.
   Алгоритм не претендует на глобальный оптимум, но быстро улучшает порядок для ≤30 точек.
3. **Связка с геометрией.** После выбора порядка `RouteService` строит дорожную геометрию через Directions API (ADR-0012) и сохраняет дистанцию/время 2ГИС.
4. **Fallback.** Если ключ/матрица недоступны, ошибка или неполная матрица, авто-порядок откатывается на прежний алгоритм по прямой; маршрут сохраняется.
5. **TSP API не используется.** Асинхронный TSP/VRP (несколько курьеров, окна, лимиты) — следующий этап; для одного курьера матрица + локальный поиск проще и предсказуемее.

## Последствия

- Плюсы: порядок учитывает реальные дороги и одностороннее движение; в смоуке дистанция снизилась с 11,15 до 6,85 км; нет асинхронных задач и polling.
- Минусы: матрица N² и синхронный лимит 5 секунд — для многих точек нужен async/кеш; локальный поиск не гарантирует оптимум; TSP/VRP-ограничения (окна, вместимость, несколько курьеров) не учтены.
- Демо-ключ и лимиты 2ГИС действуют; при сбое — прямая.

## Проверка

- Реальная матрица 5×5 (цех + 4 остановки): заказ `14,15,16,17` → `14,17,15,16`; дорожная дистанция 11,15 → **6,85 км**, время 32 мин, 319 точек геометрии.
- Тест с фейковой матрицей: порядок следует дорожным расстояниям, а не прямым. Всего **30/30**.
- Fallback: без матрицы/роутера существующие тесты по-прежнему проходят.

## Что дальше

- TSP/VRP API для нескольких курьеров, временных окон и лимитов.
- Async Distance Matrix и кеш для больших маршрутов.
- ETA по остановкам, учёт пробок и передача маршрута курьеру.
