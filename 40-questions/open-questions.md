# Открытые вопросы

> Вопрос без ответа живёт здесь, а не в переписке. Формат: вопрос → почему важно → кто решает → статус.

## Решённые (зафиксированы в спеке, 7.2)

- Один лид amoCRM = один заказ (MVP).
- `NoTare` = проблема + учёт долга.
- Приёмку подтверждает точка, авто — через `AutoConfirmDeliveryAfterMinutes`.
- Тарифы: `ClientPrice` + `CourierPay`.
- Спор после `Completed` — окно `ReopenDeliveryWindowDays`, только Head/Admin.
- Менеджер продаж не создаёт заказы напрямую.
- Один депо на тенант (MVP).
- Провайдер карт — **2ГИС** (2026-10-27, `20-decisions/ADR-0009-2gis-maps.md`).

## Как закрыть вопрос

1. Получить ответ.
2. Если ответ меняет архитектуру/продукт — создать ADR.
3. Обновить `10-spec/full-spec.md` при необходимости.
4. Перенести вопрос в «Решённые» с датой и ссылкой на ADR/раздел.
