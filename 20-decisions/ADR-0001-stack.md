# ADR-0001. Стек проекта

- Дата: 2026-10-27
- Статус: Proposed

## Контекст

Нужны: веб-панели для диспетчера/админа/руководителя, мобильное приложение курьера с офлайн-режимом, realtime-трекинг, надёжные фоновые задачи и гео-функции. Команда ориентирована на .NET (Blazor/MAUI), это задано изначально.

## Решение

- Backend: .NET 8/9, EF Core, PostgreSQL 16 + PostGIS.
- Веб-панели: Blazor Server.
- Курьер: .NET MAUI + локальный SQLite.
- Realtime: SignalR.
- Планировщик: Quartz.NET или Hangfire (выбрать до старта).
- Файлы: S3-совместимое хранилище.
- Карты: 2ГИС как основной провайдер.

## Последствия

- Плюс: единый язык C#, общая доменная модель, простая переиспользуемость DTO.
- Минус: Blazor Server чувствителен к latency; MAUI требует отдельного релизного цикла (сторы).
- Нужно: утвердить хостинг, провайдера карт, планировщик и способ доставки MAUI-приложения.
- До перевода в `Accepted` — не считать стек зафиксированным.
