# ADR-0012. Дорожная геометрия маршрутов через Directions API 2ГИС

- Дата: 2026-10-27
- Статус: Accepted

## Контекст

MVP маршрутов рисовал линию `Polyline` по координатам остановок, то есть по прямой. Демо-ключ 2ГИС включает `directions-api`, поэтому можно строить реальную дорожную геометрию, дистанцию и время. Нужно сохранить работоспособность при недоступности API.

## Решение

1. **`IRoadRouter` / `TwoGisRouter`.** Серверный клиент вызывает `POST https://routing.api.2gis.com/routing/7.0.0/global?key=...` с точками, `transport=driving`, `route_mode=fastest`, `traffic_mode=jam`, `locale=ru`.
2. **Геометрия.** Из ответа берутся `begin_pedestrian_path`, `maneuvers[].outcoming_path.geometry[]` и `end_pedestrian_path` в формате WKT `LINESTRING(lon lat, ...)`, склеиваются в один список координат. `total_distance`/`total_duration` используются для итогов маршрута.
3. **Маршрут включает цех.** Точка старта берётся из конфига `Depot` (`appsettings.json`) и добавляется к точкам остановок. Дистанция/время считаются от цеха.
4. **Fallback.** Если ключ не задан, API вернул ошибку, маршрут длиннее лимита демо-ключа (50 км) или сеть недоступна — маршрут сохраняется с прежней прямой линией и оценкой (Haversine, 30 мин на точку). Планировщик не падает.
5. **Авто-порядок.** В этом ADR порядок ещё выбирался по прямой; в ADR-0013 добавлена дорожная матрица (Distance Matrix + Or-opt), геометрия строится для выбранного порядка.
6. **UI.** `RouteDetailsDto` отдаёт `RoadGeometry`; MapGL рисует дорожную линию, если она есть, иначе — прямую. Пины остановок и цех остаются.

## Последствия

- Плюсы: на карте реальный автомобильный маршрут, километраж и время из 2ГИС; цех — точка старта; при сбое API всё продолжает работать.
- Минусы: вызов внешнего API добавляет задержку сохранения/перестроения маршрута; демо-ключ ограничен 50 км; авто-порядок не учитывает дорожную матрицу; старые подтверждённые маршруты остаются с прямой геометрией; нужны кеш/лимиты и обработка ошибок в UI.
- Ключ используется только на сервере; в браузере — только MapGL.

## Проверка

- Реальный запрос к Routing API: 3 остановки + цех → 46 точек геометрии, дистанция 1,26 км, время 5 мин (демо-данные).
- `RouteDetailsDto.RoadGeometry` заполняется; `route-map.js` использует её для `Polyline`.
- Тест с фейковым роутером: дистанция/время/геометрия берутся из `IRoadRouter`. Всего **29/29** на момент ADR; после ADR-0013 — **30/30**.
- При отсутствии роутера/ошибке — fallback на прямую (существующие тесты).

## Что дальше

- Distance Matrix + TSP для авто-порядка с учётом дорог и лимитов.
- Кеш маршрутов/матриц, ретраи, таймауты и индикатор «построено по дорогам / по прямой».
- Учёт пробок/времени и ETA по остановкам; передача геометрии курьеру в синке.
