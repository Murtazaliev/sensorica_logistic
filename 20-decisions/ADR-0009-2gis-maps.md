# ADR-0009. Провайдер карт: 2ГИС, точки доставки и геокодинг

- Дата: 2026-10-27
- Статус: Accepted

## Контекст

Диспетчеру нужно видеть точки доставки на карте, ставить и корректировать координаты, искать адрес и подтверждать точки на модерации (`PendingApproval` → `Active`). В открытых вопросах (`Q-2`) стоял выбор между 2ГИС и Яндекс.Картами. Получен ключ 2ГИС с доступом к Map Tiles API, Geocoder API и Suggest API.

## Решение

1. **Провайдер карт — 2ГИС, MapGL JS API v1.** `wwwroot/map.js` динамически загружает `https://mapgl.2gis.com/api/js/v1` и создаёт карту с ключом из конфигурации. Ключ передаётся из `IConfiguration["TwoGis:ApiKey"]`; локально хранится в **.NET user secrets**, в репозиторий не попадает. В production — переменная окружения или Vault.
2. **Координаты в `POINT`.** В `Point` и `PointSyncSnapshot` добавлены `Latitude` / `Longitude` (`double?`); в существующую dev-SQLite-базу колонки добавляются автоматически.
3. **Сервис точек (`PointService`).** Создание, обновление координат и смена статуса модерации пишутся в `SYNC_CHANGE` (`EntityType = Point`). При переводе точки в `Active` все её заказы с `IsBlockedByPointApproval = true` разблокируются, увеличивают `Version`, получают запись в историю («Точка подтверждена») и попадают в change feed.
4. **Геокодинг — на сервере.** `TwoGisGeocoder` вызывает Catalog API 2ГИС:
   - `GET /api/geocode?q=...` — координаты по адресу;
   - `GET /api/geocode/reverse?lat=...&lng=...` — адрес по координатам;
   - `GET /api/suggest?q=...` — подсказки адресов.
   Ключ используется только на сервере; клиенту отдаётся результат. Ошибки 2ГИС не раскрывают ключ.
5. **Экран `/points`.** Интерактивная карта MapGL (зелёные пины — активные, жёлтые — на модерации, синий — выбранная точка), установка координат кликом с автоопределением адреса, поиск адреса с подсказками, форма создания/редактирования и быстрая модерация.

## Последствия

- Плюсы: закрыт `Q-2`; адрес и координаты вводятся без ручного копирования; модерация точки сразу разблокирует заказы; курьеры получают изменения точек через тот же delta pull.
- Минусы: ключ MapGL виден в браузере (это нормально для клиентского ключа, но требует ограничений по домену в кабинете); Geocoder/Suggest — платные сетевые вызовы, нужны кеш и лимиты. Routing и Distance Matrix позже подключены в ADR-0012/0013; TSP/VRP ещё впереди.
- Автотестами покрыт парсинг ответов геокодера; визуальный рендер карты проверяется в браузере (headless-WebGL тайлы не рисует).

## Проверка

- Ключ активен: `keys.api.2gis.com` → `is_active = true`; стиль и векторные тайлы отдают HTTP 200.
- Реальные вызовы: геокодинг «Тверская, 12» → 10 результатов; reverse по координатам → адрес; подсказки → 8 вариантов.
- `GET /points` — 200, карта инициализируется, форма и справочник отображаются.
- Модерация точки разблокирует заказы и пишет change feed (тесты).
- Тесты: **23/23** (4 новых — геокодер).

## Что дальше

- Добавить ограничение ключа по домену и прод-хранение секрета (Vault/переменные окружения).
- Кеширование геокодинга и лимиты запросов.
- Routing API / Distance Matrix / TSP для маршрутов и порядка объезда.
