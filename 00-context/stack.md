# Стек и инфраструктура

> Статус: **Proposed** — финально не утверждён (см. ADR-0001). Не считать обязательным, пока ADR не переведён в `Accepted`.

## Backend

| Компонент | Выбор | Назначение |
|---|---|---|
| Платформа | .NET 10 | API + домен (реализация начата) |
| Web-панели | Blazor Server | Диспетчер, админ, руководитель, мини-панель менеджера |
| Аутентификация | Cookie + `PasswordHasher` | MVP: пароль и роли; OTP — следующий этап (ADR-0010) |
| Мобильный клиент | .NET MAUI | Курьер, offline-first |
| ORM | EF Core | Доступ к данным, миграции |
| API-документация | Swashbuckle (OpenAPI) | Swagger UI, только Development |
| БД | PostgreSQL 16 + PostGIS | Целевое хранилище; на этапе мока используется SQLite |
| Realtime | SignalR | Трекинг, чат, обновление статусов |
| Планировщик | Quartz.NET или Hangfire | Cutoff, блокировки, отложенные уведомления |
| Кэш/эфимерное | Redis | Координаты курьеров, распределённые блокировки |
| Файлы | S3-совместимое хранилище (MinIO/S3) | Фото, подписи, акты |
| Push | FCM + APNs | Уведомления курьеру |
| QR | ZXing.Net | Сканирование QR точки |
| Карты | 2ГИС: MapGL JS API + Geocoder/Suggest API (ADR-0009) | Карта, адресные подсказки, координаты; маршруты — следующий этап |
| Документы | ЭДО: Diadoc/Taxcom/Astral | ЭТрН/акты (после MVP) |

## Клиенты

- **Blazor Server** — веб-панели (диспетчер, админ, руководитель, менеджер продаж).
- **PWA** — менеджер точки (можно как отдельный Blazor-проект или лёгкий SPA).
- **.NET MAUI** — курьер; локальный SQLite, очередь операций, синк.

## Инфраструктура

- Контейнеры: Docker.
- CI/CD: GitHub Actions / GitLab CI (уточнить).
- Хостинг: уточнить (облако РФ / on-prem).
- Наблюдаемость: OpenTelemetry, Serilog, health-checks.
- Секреты: Vault / переменные окружения (не в репозитории).

## Открытые вопросы

- Хостинг и требования 152-ФЗ (данные на территории РФ).
- Нужен ли Redis на старте или достаточно памяти процесса.
- Blazor Server vs WASM для мини-панели менеджера.
