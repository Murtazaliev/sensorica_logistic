# ADR-0004. Один депо на тенант (MVP)

- Дата: 2026-10-27
- Статус: Accepted

## Контекст

`Tenant` содержит один адрес и координаты депо. Неизвестно, будут ли у клиента несколько складов.

## Решение

В MVP — один депо на тенант (`Tenant.Address/Lat/Lng`). Модель проектируется так, чтобы позже добавить `WAREHOUSE` без ломки маршрутов.

## Последствия

- Плюс: проще геофенс, старт маршрута, планирование.
- Минус: мультисклад не поддерживается.
- Нужно: подтвердить у заказчика; при необходимости — отдельный ADR на `WAREHOUSE`.
