# Глоссарий

| Термин (RU) | Код / EN | Определение |
|---|---|---|
| Тенант | `Tenant` | Цех/компания-клиент системы. Изолирует данные. |
| Депо | `Tenant.Address/Lat/Lng` | Точка старта маршрутов, склад цеха. |
| Точка доставки | `Point` | Магазин/кафе/клиент, куда везут заказ. |
| Менеджер точки | `PointManager` | Сотрудник точки, подтверждает приёмку в PWA. |
| Заказ | `Order` | Заказ на доставку, создаётся из сделки amoCRM. |
| Позиция заказа | `OrderItem` | Строка состава заказа (продукт, количество). |
| Маршрут | `Route` | Набор точек на дату для одного курьера. |
| Точка маршрута | `RoutePoint` | Заказ в маршруте с порядковым номером. |
| Доставка | `Delivery` | Факт доставки: время, подпись, фото. |
| Проблема | `Problem` | Инцидент при доставке (закрыто, отказ, нет тары…). |
| Тара | `Tare` | Возвратная тара (ящики, контейнеры). |
| Движение тары | `TareMovement` | Выдача/возврат тары. |
| Долг по таре | `TareDebt` | Разница выданного и возвращённого. |
| Cutoff | `CutoffTimeForTodayOrders` | Время, после которого заказы «на сегодня» не принимаются. |
| Блокировка планирования | `PlanningLockTime` | Время, после которого маршруты на сегодня нельзя менять. |
| Старт доставки | `DeliveryStartTime` | Время, с которого курьер может забрать заказы. |
| Перенос | `IsDeferred` | Заказ автоматически перенесён на следующий рабочий день. |
| Рабочий календарь | `WorkingCalendar` | Выходные/праздники для расчёта `nextBusinessDay`. |
| Outbox | `OutboxEvent` | Надёжная очередь исходящих вызовов (PATCH amoCRM и др.). |
| Мок-интеграция | `MockAmoIntake` | Имитация amoCRM через фикстуры на этапе разработки. |
| Идемпотентность | `ClientOperationId` | Ключ, защищающий от дублей при повторе операции. |
| Tombstone | `IsDeleted/DeletedAt` | Маркер удаления для офлайн-синхронизации. |
| Воронка | Pipeline | Воронка amoCRM; стадии принадлежат воронке. |
